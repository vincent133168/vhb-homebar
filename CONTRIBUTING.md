# Contributing

Thanks for helping improve VHB Homebar.

1. Fork the repository and create a focused branch.
2. Keep customer data, real credentials, and private deployment IDs out of commits.
3. Run `npm run build` before opening a pull request.
4. Describe the user impact and validation performed.
5. Keep alcohol-related content intended for adults and avoid encouraging excessive drinking.

For security issues, follow `SECURITY.md` instead of opening a public issue.
